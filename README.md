# Aurora TV

Видеоплеер для Google TV / Android TV (Android 9–16, API 28–36), рассчитанный на управление пультом. Media3 ExoPlayer, системные аппаратные декодеры и системный аудиовыход телевизора.

## Версия 3.5.0

- **Управление файлами в проводнике** (USB и домашняя сеть): удерживайте OK на файле или папке — «Переименовать», «Переместить в другую папку», «Удалить», «Отметить просмотренным» / «Сбросить просмотр».
  - Субтитры рядом с видео переименовываются, переносятся и удаляются вместе с ним. Позиция просмотра и история переезжают вслед за файлом.
  - «Переместить»: откройте нужную папку и нажмите «Вставить сюда». На другой диск файл копируется с процентами, операцию можно остановить. В сети перенос делает сам сервер.
  - «Новая папка» и сортировка: по имени, сначала новые, сначала большие.
  - Удаление всегда спрашивает подтверждение, корзины нет.
- **Мышь**: левая кнопка нажимает, правая открывает меню файла (где меню нет — «Назад»), колесо прокручивает, фокус следует за указателем. В плеере клик по шкале перематывает, клик по картинке показывает или прячет панель.
- **Курсор пультом**: «Мой телевизор» → «Курсор пультом». Стрелки плавно двигают указатель (чем дольше держать, тем быстрее), OK нажимает, долгое OK — правая кнопка, у края экрана страница прокручивается. Указатель прячется, если пульт не трогать.
- «Поддержать автора» перенесено на главный экран, рядом с «Выберите источник».
- Быстрее и стабильнее:
  - Папки на USB читаются примерно вдвое быстрее (один запрос атрибутов на файл), а при возврате назад открываются сразу из памяти.
  - Сортировка больших папок без лишних расчётов.
  - Позиции пишутся на флешку ТВ одной записью вместо двух.
  - Буфер плеера подстраивается под память приставки: меньше вылетов на слабых и больше запас для 4K по сети на мощных.
  - Фон «Северное сияние» больше не создаёт новые градиенты на каждом кадре.

## Версия 3.4.0

- **Домашняя сеть без повторного ввода пароля.**
  - Новый переключатель «Запомнить»: пароль хранится зашифрованным ключом Android Keystore и никогда не покидает этот ТВ.
  - После перезапуска приложения сетевая папка открывается сама, «Продолжить просмотр» и плеер переподключаются молча.
  - Последние подключения показываются кнопками «Сохранённые», забыть их можно в «Мой телевизор» → «Сетевые папки».
  - NAS, Samba и macOS, которые объявляют себя в сети, показываются в «Найдены в сети».
  - Если оставить «Общая папка» пустым, плеер покажет все папки сервера.
  - Если сервер не принимает SMB 2, плеер пробует SMB 3. Ошибки названы по существу: сервер не отвечает, неверный пароль, папка не найдена.
- **Субтитры рядом с видео подключаются сами**: `Фильм.srt`, `Фильм.ru.srt`, `Фильм.eng.forced.ass`. Язык берётся из имени файла.
- **Субтитры в Windows-1251 читаются правильно**, кириллица больше не превращается в «кракозябры». Это касается и файлов, выбранных вручную.
- **Плавная перемотка**: при удержании ←/→ плеер двигает отметку и показывает, на сколько перематывает (`▶▶ +2:30`). Переход делается один раз, когда кнопку отпустили, поэтому 4K по сети больше не захлёбывается.
- **Переподключение при обрыве сети**: плеер сам повторяет попытку до трёх раз («Связь прервалась · переподключаюсь») и только потом показывает ошибку. Прямой эфир HLS, отставший от трансляции, возвращается к эфиру без ошибки.
- **Таймер сна**: «Настройки» → «Таймер сна»: 15 минут – 2 часа или «После этого файла». Плеер ставит паузу, запоминает место и даёт ТВ уснуть.
- **Время окончания**: под часами в плеере написано «закончится в 23:41» с учётом скорости. На карточке «Далее» идёт обратный отсчёт.
- **Дорожки запоминаются для каждой папки**: оригинал в одном сериале не переключает озвучку в другом. Новая папка начинает с последнего выбора, как раньше.
- Настраивается шаг перемотки назад (5–30 секунд).
- «Мой телевизор» → «Отчёт о сбое»: если плеер закрылся с ошибкой, здесь виден текст для автора. Сам плеер никуда его не отправляет.
- Стабильность: при переподключении закрываются старые SMB-соединения, двойное нажатие OK не запускает два плеера, очень большие папки не ломают запуск (в плейлист попадают 300 файлов вокруг выбранного), позиции файлов, которые не открывались больше года, удаляются, а обновление не зависает в «Устанавливаю…».
- Обновлён BouncyCastle до 1.86 (в 1.76, которую тянет jcifs-ng, есть уязвимости). AGP остаётся 9.2.1 — новее пока не поддерживает Android Studio.

Сквозная передача звука на ресивер работает как раньше. Если декодер ТВ не справился, карточка ошибки предлагает «Программный декодер». Есть режимы «Только аппаратный» и «Программный FFmpeg».
- **Частота кадров экрана** (Мой телевизор):
  - «Выключено»;
  - «Только плавно» — по умолчанию, как раньше;
  - «Как у видео» — экран переключается на 23,976 / 24 / 25 / 50 / 59,94 Гц под фильм, работает на Android 9–16.

- **Отчёт «Мой телевизор»**: возвращена таблица аппаратного видео по разрешениям 720p / 1080p / 1440p / 4K (как в 2.x), добавлен раздел о FFmpeg.

Большие файлы: размер ограничивают только файловая система накопителя и ТВ. FAT32 не хранит файлы больше 4 ГБ, поэтому для фильмов 50–100 ГБ используйте exFAT или NTFS, если телевизор их монтирует. - **Сетевые папки**: перемотка в SMB-файле теперь мгновенная (позиционирование вместо чтения до нужного места). Поля ввода не открывают клавиатуру случайно при навигации.

  - в одном плейлисте можно смешивать сетевые папки и ссылки HTTP/HLS/DASH.

## Возможности

- Файлы с USB-накопителя и внутренней памяти. Накопители показывает сам плеер, сторонний файловый менеджер не нужен. Читается только текущая папка, весь диск не обходится. На Android 11+ один раз нужно разрешить «Доступ ко всем файлам»: плеер откроет нужный экран настроек. Файлы меняются только по команде из меню файла (удерживайте OK).
- Отдельный файл через системный выбор и прямые ссылки HTTP(S), включая HLS и DASH.
- Домашняя сеть по SMB 2 и 3: ПК и NAS по имени или IP, логин и пароль, гостевой доступ, список папок сервера, поиск NAS в сети. Пароль по выбору хранится зашифрованным на ТВ, иначе — до закрытия приложения.
- Выбор встроенных аудиодорожек и субтитров, внешние SRT/VTT/ASS рядом с видео. Выбранная дорожка запоминается для папки между сериями и запусками по языку и названию.
- Таймер сна, время окончания фильма, автоматическое переподключение при обрыве сети.

## Кодеки, HDR и 4K/60

Видео декодируется системными декодерами Android TV: H.264, HEVC, VP9, AV1 и Dolby Vision работают там, где их предоставляет прошивка. При ошибке первого декодера включается запасной. «Мой телевизор» и «Настройки → Информация о декодерах» показывают заявленные прошивкой возможности. Это не тест конкретного файла. Сторонние программные кодеки в APK не включены.

## Звук через оптику (пример: TCL S643W)

На саундбаре выберите вход Optical, на телевизоре — оптический аудиовыход и цифровой формат Auto или Pass-through. Если дорожка не звучит, попробуйте PCM или другую дорожку в плеере. Оптика не передаёт Dolby TrueHD/Atmos и многоканальный PCM. При скорости, отличной от 1×, сквозная передача сжатого звука может отключаться.

## Домашняя сеть

Откройте «Домашняя сеть» и введите адрес ПК или NAS (например `192.168.1.20`, без `smb://`) и имя общей папки. Если имя папки неизвестно, оставьте поле пустым и нажмите «Подключить»: плеер покажет папки сервера. NAS из «Найдены в сети» подставляется одним нажатием. Для гостевого ресурса оставьте пользователя и пароль пустыми. Пользователя домена укажите как `DOMAIN\user`. Плеер сначала подключается по SMB 2.0–2.1, а если сервер их не принимает — по SMB 3.x. SMB1 отключён намеренно. С включённым «Запомнить» пароль шифруется ключом Android Keystore и после перезапуска не нужен. Для 4K с высоким битрейтом лучше Ethernet или быстрый Wi-Fi.

## Сборка

AGP 9.2.1, Gradle 9.8.2, Kotlin 2.4.21, Compose for TV (tv-material 1.1.0, BOM 2026.09.00), Media3 1.11.1, NextLib 1.11.1-0.16.0, jcifs-ng 2.1.10. Нужны JDK 17+ и Android SDK Platform 37. Путь к SDK задаётся в `local.properties` (`sdk.dir=D\:\\SDK`).

```powershell
.\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:lintDebug
.\gradlew.bat :app:assembleRelease
```

В release включены R8 и сжатие ресурсов (`app/proguard-rules.pro` сохраняет классы jcifs). Релиз подписывается ключом из `keys/aurora-tv-release.jks` с параметрами из `signing.properties`. Оба файла исключены из Git. Храните их отдельно: без ключа нельзя обновить установленное приложение.
